# Excel Sales Performance Dashboard

## Project Overview

An interactive Excel dashboard built to analyze sales performance across cities and sales executives.

## Key Features

* Interactive city filters for sales analysis.
* Four checkbox-controlled dashboard views.
* Sales comparison across sales executives.
* Target Hit Percentage analysis.
* Away From Target Percentage analysis.
* Pivot Tables and charts for data visualization.
* Raw data maintained in a separate worksheet.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Interactive Filters
* Charts and Data Visualization
